# ワカルート レッスンコンテンツ制作ガイド

更新日: 2026-08-04  
状態: Draft 0.1

## 1. このガイドの目的

このガイドは、中学生が高校受験に必要な内容を「読んだ」だけで終わらず、理解し、思い出し、自分で使える状態になるレッスンを作るための共通基準です。

個々のレッスンを長くすることが目的ではありません。コース、セクション、前後のレッスンの役割を整理し、各レッスンが担当する一つの仕事を、必要十分な深さで完了させることを目指します。

対象は数学に限りません。国語、英語、理科、社会にも適用し、教科や学習内容に応じて説明、暗記、練習、読解、活用の比重を調整します。

## 2. 基本原則

### 2.1 最初にレッスンの役割を明示する

生徒がタイトルから期待する内容と、実際の内容を一致させます。レッスン冒頭では、少なくとも次を伝えます。

- このレッスンで何を学ぶか
- このレッスンがコースのどこにあるか
- 何を知っていれば始められるか
- 何ができれば完了か
- 次のレッスンで何につながるか
- この内容に合う勉強法は何か

「基本を理解しよう」というタイトルなら、基本事項そのものを十分に説明します。全体像だけを扱う場合は、「全体像」「学習の見取り図」「はじめに」など、概要であることが分かる名前にします。

### 2.2 一つのレッスンには一つの中心技能を置く

一つのレッスンで診断したい理解目標を一つに絞ります。

例:

- 方程式の解の意味を説明できる
- `x+a=b` 型で使う逆操作を選べる
- 移項の符号が変わる理由を説明できる
- 分配法則のかけ忘れを発見できる

複数の技能を扱う場合も、主技能と補助技能を区別します。クイズで間違えたときに、どこへ戻ればよいか特定できないレッスンは、範囲が広すぎる可能性があります。

### 2.3 単独でも役割を果たし、前後と重複しすぎない

レッスン単独で、そのレッスンが約束した理解目標を達成できる内容を入れます。一方で、コース全体を毎回説明し直しません。

重複は次の場合だけ意図的に使います。

- 新しい内容に必要な前提を短く思い出させる
- 重要事項を時間を空けて再確認する
- 別の場面で使い、知識を転移させる
- よくある誤解を別の角度から修正する

### 2.4 説明量ではなく認知負荷で分ける

文章量が短くても、新しい概念が多ければ難しいレッスンです。次のいずれかに当てはまる場合は分割を検討します。

- 新しい用語や考え方が二つ以上ある
- 異なる計算手順を二つ以上教える
- 例題を理解する前提が途中で追加される
- 一つの誤答から複数の原因が考えられる
- 読了と自己確認に10分以上かかる
- クイズの不正解から弱点を一つに特定できない

### 2.5 細かく診断し、最後は大きく統合する

細かなレッスンとクイズは弱点の発見に向いています。ただし、細かい問題だけでは、複数の知識を選んで使う力は育ちません。

学習確認は次の三段階で設計します。

1. レッスン直後: 一つの技能を確認する
2. セクション終了時: 複数の技能を混ぜる
3. コース終了時: 単元横断・高校入試形式で統合する

## 3. コース、セクション、レッスンの役割

### 3.1 コース

コースは、一つの単元で最終的に身につける力と学習順序を示します。コースの最初に、次を提示します。

- 到達目標
- 対象学年
- 必要な前提知識
- 学習タイプと推奨する勉強法
- セクションの順序と依存関係
- 完了の判定方法
- 高校入試での使われ方

### 3.2 セクション

セクションは、関連する複数の技能をまとめた学習段階です。セクションの冒頭では、前のセクションとの接続と、内部のレッスン順序を示します。

標準的な構成は次のとおりです。ただし、すべてのセクションへ機械的に同じ数を入れません。

1. 全体像または導入
2. 前提確認と勉強法
3. 意味と基本
4. 基本の分解
5. 例題と誤答分析
6. 練習と定着
7. 応用または入試への接続

目安となるレッスン数:

| セクションの性質 | 目安 | 例 |
|---|---:|---|
| 用語・導入 | 3〜4 | 方程式、未知数、解の意味 |
| 基本操作 | 4〜6 | 一次式の加減、平方根の計算 |
| つまずきやすい概念 | 5〜8 | 移項、割合、関数、証明 |
| 総合・マスターチェック | 3〜5 | 弱点診断、混合練習、入試問題 |

### 3.3 レッスン

レッスンは、一回の集中で一つの理解目標を完成させる最小単位です。内容量の目安より、次の完了条件を優先します。

- 意味を説明できる
- 基本操作を自力で再現できる
- 典型的な誤りを見抜ける
- 答えを元の条件へ戻して確認できる
- 次のレッスンへ進む準備ができている

### 3.4 セクション内でのポジション

生徒は、すでに特定のコースとセクションへ入った状態でレッスンを読みます。各レッスンを独立した記事として書くだけでなく、セクション内の連続した学習体験として設計します。

各レッスンには、次の三つの接続を持たせます。

1. 前から受け取るもの: 直前までに理解している技能
2. 今回完成させるもの: このレッスンだけが主に担当する技能
3. 次へ渡すもの: 次のレッスンで前提として使う技能

前後関係は、冒頭と末尾に案内文を置くだけでは不十分です。本文の説明、例題、練習にも反映します。前のレッスンで得た技能は、もう一度最初から教え直すのではなく、今回の例題で実際に使います。次のレッスンで必要になる判断は、今回の最後の練習で一度経験させます。

つまり、各レッスンは「前の内容を消費し、今回の技能を完成させ、次に必要な状態を生産する」単位として設計します。

冒頭では、コース全体を毎回説明し直しません。現在のセクション名を前提に、前回との違いと今回の役割を短く伝えます。

例:

> 前のレッスンでは、足し算と引き算を逆の操作で取り除きました。今回は、xに数がかかっている場合と、xが数で割られている場合を扱います。ここができると、次の混合練習で式の形に合う操作を自分で選べます。

セクション内の位置によって、レッスンの書き方も変えます。

| 位置 | 主な役割 | 冒頭で伝えること | 終了時に確認すること |
|---|---|---|---|
| 最初 | セクションへの入口 | 前のセクションとの接続、全体像、必要な前提 | 学習順と最初の基本が分かったか |
| 中盤 | 技能の積み上げ | 直前で得た技能、今回追加する違い | 次で組み合わせられる状態か |
| 後半 | 統合と転移 | どの技能を選び分けるか | 初めて見る形でも使えるか |
| 最後 | 定着と出口 | セクション全体で得た技能 | 次のセクションへ進めるか、どこへ戻るか |

#### セクション内カバレッジ表

本文を書く前に、セクション内の各レッスンが何を担当するかを並べます。

例: 「基本の一次方程式」セクション

| 順番 | レッスン | 主に担当すること | 前から受け取るもの | 次へ渡すもの |
|---:|---|---|---|---|
| 1 | 全体像 | 基本三形式と学習順 | 等式の性質 | セクションの見通し |
| 2 | 正負の数と逆算 | 符号と逆操作 | 正負の数 | 基本式を解く準備 |
| 3 | `x+a=b` 型 | 加減の逆操作 | 逆算 | 形に応じた操作選択 |
| 4 | `ax=b`、`x÷a=b` 型 | 乗除の逆操作 | 係数と除法 | 三形式の比較 |
| 5 | 混合練習 | 解法の選択と定着 | 基本三形式 | 移項を含む式への準備 |

この表で、同じ説明が複数レッスンの主目的になっていないか、前提なしに新しい技能が現れていないか、最後のレッスンが次のセクションへ接続しているかを確認します。

#### ポジションの表示

可能であれば、画面またはレッスン情報に次を表示します。

- セクション名
- セクション内の順番、例: 3 / 5
- 役割、例: 基本、例題、練習
- 前のレッスンで学んだこと
- 次のレッスンで扱うこと

ただし、ナビゲーション情報を長い説明文として本文へ繰り返しません。生徒が現在地と次の一歩を迷わないために必要な量だけ示します。

## 4. 書き始める前のレッスン設計票

本文を書く前に、各レッスンについて次を決めます。

| 項目 | 記入内容 |
|---|---|
| レッスンタイトル | 内容の深さと役割が分かる名前 |
| レッスンの役割 | 導入、前提、理解、手順、例題、誤答、練習、応用、総合 |
| 中心技能 | クイズで一つに診断できる技能 |
| 学習タイプ | 理解、手順、知識定着、読解・説明、活用、混合 |
| セクション内ポジション | 最初、中盤、後半、最後、および全体の何番目か |
| 前提レッスン | このレッスン開始前に必要な内容 |
| 前から受け取る技能 | 直前のレッスンまでに使える状態の技能 |
| 完了後にできること | 生徒の行動として表す |
| このレッスンで扱うこと | 必ず説明する範囲 |
| このレッスンで扱わないこと | 後のレッスンへ送る範囲 |
| 典型的な誤解 | クイズとフィードバックに使う |
| 推奨時間 | 読む、考える、自己確認を含む時間 |
| 次のレッスン | ここで学んだことの使い道 |
| 次へ渡す技能 | 次のレッスンが前提として使う技能 |

### 4.1 タイトルの確認

タイトルは、生徒との約束です。

良い例:

- 方程式・未知数・解を見分けよう
- 移項はなぜ符号が変わるのか
- 分数の方程式から分母をなくそう
- 誤った証明の最初の間違いを見つけよう

避けたい例:

- 基本を理解しよう
- しっかり学ぼう
- 応用してみよう

抽象的なタイトルを使う場合は、概要レッスンであることを明示します。

## 5. 学習タイプと勉強法

レッスン冒頭で、内容に合う学び方を短く伝えます。

| 学習タイプ | 主な対象 | 有効な勉強法 | 避けたい状態 |
|---|---|---|---|
| 理解中心 | 方程式の意味、関数、証明 | 図と言葉で説明し、理由を声に出す | 規則だけを暗記する |
| 手順習得中心 | 計算、作図、文法操作 | 一行一操作で再現し、徐々に補助を減らす | 解答を見ながらまね続ける |
| 知識定着中心 | 漢字、英単語、理社用語 | 思い出す練習と間隔反復 | 読み返すだけで覚えたと思う |
| 読解・説明中心 | 国語、証明、資料問題 | 根拠箇所を示し、主張と理由を分ける | 感想だけで答える |
| 活用中心 | 文章題、関数と図形、入試総合 | 条件を整理し、使う知識を自分で選ぶ | 直前の例題の型へ無理に当てはめる |
| 混合 | セクション・コース総合 | 異なる問題を混ぜ、解法選択を練習する | 同じ型だけを連続して解く |

勉強法の案内は精神論にしません。「頑張ろう」ではなく、次の行動を具体的に示します。

例:

> このレッスンは暗記ではありません。式を変形するたびに、両辺へ何をしたか声に出してください。

> 漢字は見直すだけでなく、答えを隠して思い出して書きます。翌日と一週間後にも再確認します。

## 6. レッスン本文の標準構成

すべてを毎回入れる必要はありませんが、役割に応じて次から選びます。

### 6.1 役割と期待値

冒頭で、次の情報を短く示します。

- このレッスンの役割
- 身につける一つの技能
- 前提となる内容
- 完成の目安
- おすすめの勉強法

### 6.2 興味を引く問い

最初の30秒で、「なぜ学ぶのか」「何が不思議なのか」が分かる問いを置きます。

抽象的な問い:

> 何を理解し、どの順番で考えるとよいでしょうか。

具体的な問い:

> `x+7=12` の `+7` を消したいとき、なぜ両辺から7を引くのでしょうか。

生徒がすでに知っている場面、意外な結果、よくある間違いから始めると集中しやすくなります。

### 6.3 前提確認

必要な前提だけを2〜3問で確認します。前提の説明が本編より長くなる場合は、別レッスンへ分けます。

### 6.4 基本説明

説明は次の順序を基本とします。

1. 身近な場面や具体物
2. 図、表、数直線、天びんなどの視覚表現
3. 数や式を使った具体例
4. 一般的な言葉、定義、公式
5. 公式が使える条件

公式を最初に置く場合も、意味と条件を後回しにしません。

### 6.5 例題

例題は次の構造で書きます。

1. 問題
2. 最初に見る条件
3. 方針を選ぶ理由
4. 一行ずつの処理
5. 各行で何をしたか
6. 答え
7. 元の式や場面での確認

一つ目は完全な解説付き、二つ目は一部の補助を減らし、三つ目は自力で考える構成が基本です。

### 6.6 誤答分析

正解だけでなく、よくある間違いを教材として使います。

- 最初に正しくなくなった行はどこか
- 何を理解していなかったか
- 計算、意味、読解のどの種類の誤りか
- どの前提レッスンへ戻るべきか

生徒の人格や能力を評価せず、修正できる行動として説明します。

### 6.7 自己確認と次への接続

本文の最後に、次を確認します。

- 何も見ずに基本を再現できるか
- 理由を一文で説明できるか
- 典型的な誤りを直せるか
- 次のレッスンで何に使うか分かるか

## 7. 集中力を切らさない設計

### 7.1 一回の集中で完了できる長さにする

時間の目安:

| レッスンの役割 | 目安時間 | 本文量の参考 |
|---|---:|---:|
| 導入・前提確認 | 3〜5分 | 700〜1,200字 |
| 概念理解 | 5〜8分 | 1,200〜2,000字 |
| 手順・例題 | 6〜10分 | 1,500〜2,400字 |
| 誤答分析・練習 | 5〜8分 | 問題数と解説で調整 |

文字数は上限やノルマではありません。式、図、表、操作に必要な時間を含めて判断します。

### 7.2 情報の見せ方を切り替える

長い説明を続けず、意味のある単位で表現を切り替えます。

- 短い説明
- 数式または具体例
- 図、SVG、表、チャート
- 自分で考える問い
- 誤答の比較
- まとめ

見た目を変えるためだけの図やカードは使いません。表現を変えるたびに、理解が一段進む必要があります。

### 7.3 文章の読みやすさ

- 一文で一つの主張を伝える
- 中学生が知らない言葉は、その場で説明する
- 段落を長くしすぎない
- 数式の前後に十分な空間を取る
- 主語や単位を省きすぎない
- 「これ」「それ」が何を指すか明確にする
- 命令だけでなく、理由も伝える

表示上の目安:

- 本文は16〜18px程度
- 行間は1.7〜1.9程度
- 一行を長くしすぎない
- モバイルで表やSVGが横にはみ出さない

## 8. 図・SVG・表・チャート

視覚表現は装飾ではなく、文章だけでは分かりにくい関係を見せるために使います。

優先する例:

- 正負の数: 数直線、方向、温度差
- 方程式: 天びん、逆操作、左右の同じ変化
- 展開・因数分解: 面積図
- 関数: 場面、表、式、グラフの対応
- 図形: 対応する辺・角、補助線、変形
- データ: 分布、比較、軸の違い
- 国語: 文章構造、主張と根拠
- 理科・社会: 因果、時間順序、比較

制作ルール:

- SVGには`title`と`desc`を付ける
- `viewBox`を使い、幅をレスポンシブにする
- 色だけで意味を伝えない
- 画像内へ長い本文を焼き込まない
- 同じ汎用フロー図をすべてのレッスンへ繰り返さない
- 図を見た後に何を読み取るか文章でも示す
- 操作可能な図はキーボードと動きの軽減設定へ対応する

## 9. 確認クイズと学習分析

### 9.1 レッスン直後のクイズ

一つのレッスンにつき2〜4問を基本とします。

1. 意味を理解しているか
2. 基本操作ができるか
3. よくある間違いを見抜けるか
4. 少し形を変えても使えるか

すべてのレッスンへ同じ種類の選択問題を置く必要はありません。説明、並べ替え、誤答選択、式と場面の対応など、技能に合う形式を選びます。

### 9.2 問題に持たせる情報

学習分析のため、問題には次の情報を持たせます。

- `skillId`: 確認する中心技能
- `lessonId`と`sectionId`
- 難易度
- 問題形式
- 必要な前提技能
- `misconceptionId`: 想定する誤解
- 誤答の種類: 理解、手順、計算、読解、注意、記述
- 回答時間
- 試行回数
- ヒント利用の有無

### 9.3 フィードバック

「不正解です」だけで終わらせません。

良いフィードバック:

> 計算ではなく、等式の両辺へ同じ操作をする理由で止まっています。「天びんで等式の性質を理解しよう」へ戻りましょう。

弱点の判定は、一問だけで断定しません。同じ技能を異なる角度から確認し、誤答傾向、回答時間、再挑戦結果を組み合わせます。

### 9.4 累積確認

- セクション確認: 直前の複数技能を混ぜる
- コース確認: 以前の内容も含めて思い出す
- 入試確認: 問題文から使う技能を自分で選ぶ

## 10. 教科ごとの重点

### 数学

- 公式より意味と条件を先にする
- 一行ごとの理由を説明する
- 誤答の最初の行を特定する
- 基本問題、混合問題、文章題を分ける
- 図、式、言葉を行き来する

### 国語

- 語句知識、読解、根拠説明を分ける
- 本文のどこを根拠にしたか示す
- 読み方の手順を、別の文章でも使える形にする
- 漢字と語彙は間隔反復と想起練習を使う

### 英語

- 文字と音、語彙、文法、読解、表現を混同しない
- 初学者には日本語との違いを明示する
- 音、語順、意味を対応させる
- 文法規則の直後に短い運用例を置く

### 理科

- 観察事実、モデル、法則、計算を区別する
- 原因と結果を図にする
- 実験条件と変える条件を明確にする
- 用語暗記だけで現象を理解したことにしない

### 社会

- 用語、場所、時間、因果、比較を分ける
- 「なぜそうなったか」と「その結果」をつなぐ
- 地図、年表、資料を根拠として使う
- 興味を引く問いから制度や用語へ進む

## 11. 品質評価ルーブリック

11項目を0〜2点、22点満点で評価します。

| 観点 | 0点 | 1点 | 2点 |
|---|---|---|---|
| 役割 | 不明 | 一部伝わる | 冒頭で明確 |
| 中心技能 | 複数で診断不能 | やや広い | 一つに診断可能 |
| 前後関係 | 重複・抜けがある | 暗黙的 | 前提と次が明確 |
| セクション内ポジション | 単独記事になっている | 順番だけ分かる | 前から受け取り、今回完成させ、次へ渡す技能が明確 |
| 基本説明 | 結論だけ | 手順はある | 意味・理由・条件がある |
| 例題 | ない | 答え中心 | 方針・途中・確認まである |
| 誤答対応 | ない | 注意だけ | 原因と戻り先が分かる |
| 集中力 | 長い単調な説明 | 一部変化 | 適切に分割・切替される |
| 視覚表現 | 装飾または不適切 | 一部役立つ | 理解を明確に進める |
| 自己確認 | 一般論だけ | 基本一問 | 中心技能を複数角度で確認 |
| 言葉 | 難しい・曖昧 | 一部説明不足 | 中学生に明確で誠実 |

公開の目安:

- 合計18点以上
- 役割、中心技能、基本説明、自己確認がすべて2点
- 数学的・教科的な誤りがない
- デスクトップとモバイルで表示確認済み

## 13. 全面書き直しの進め方

既存レッスンをすぐ上書きせず、次の順序で進めます。

1. コースの到達目標と学習タイプを決める
2. セクション間の前提関係を確認する
3. 既存レッスンを役割別に分類する
4. 概要として残すもの、詳細化するもの、統合するものを決める
5. 各レッスンの設計票を作る
6. 前提、基本、例題、誤答、練習、応用のカバレッジ表を作る
7. 本文を書く
8. 教科内容と中学生向け表現を別々にレビューする
9. クイズと誤答タグを作る
10. MCP上の件数、公開状態、前後順を確認する
11. localhostでデスクトップとモバイルを確認する
12. 一つのコースで基準を確立してから全教科へ展開する

### 13.1 既存の総合レッスンの扱い

現在の一部レッスンは、意味、手順、確認を広く扱う概要として利用できます。内容が正しくても、タイトルが約束する深さに足りない場合があります。

その場合は次のいずれかを選びます。

- 「全体像」「学習の見取り図」として役割を明示して残す
- 数学固有・教科固有の説明を加えて詳細レッスンへ直す
- 前後の詳細レッスンへ内容を分ける
- 重複する概要を統合する

評価はレッスン単独の文字数だけでなく、前後を含むセクション全体のカバレッジで行います。

## 14. 推奨するコンテンツメタデータ

## 15. このガイドの更新方針

この版は、現在までの数学レッスン制作とレビューから得た基準をまとめた初版です。次の作業で更新します。
