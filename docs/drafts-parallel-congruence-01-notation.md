Title: 角の名前を3文字で読もう

Summary: 角の頂点を中央に置く約束を使い、3文字の角の記号から二つの辺と頂点を正しく読み取る。

# 角の名前を3文字で読もう

## このレッスンの役割

このレッスンは「角と図形の記号を読み直そう」の1 / 5、平行線と合同を学ぶ入口です。平面図形で使った点と線分の名前を受け取り、ここでは角を3文字で正確に読む力を完成させます。できた目安は、図の向きが変わっても、記号が表す角を指せることです。

## おすすめの学び方

3文字を一度に暗記せず、「辺をたどる → 頂点で曲がる → もう一方の辺へ進む」と声に出します。中央の文字へ丸を付けると、頂点の読み違いを防げます。

## 今日の問い

`∠ABC` と `∠CBA` は、同じ角を表すでしょうか。

## 具体例で考えよう：中央の文字が頂点

角は、同じ端点から出る二つの半直線が作る開きです。`∠ABC` では中央の `B` が頂点です。辺 `BA` から頂点Bを通り、辺 `BC` へ進む角を表します。

| 記号 | 頂点 | 角を作る二つの辺 |
|---|---|---|
| `∠ABC` | B | BAとBC |
| `∠CBA` | B | BCとBA |
| `∠BAC` | A | ABとAC |

したがって `∠ABC` と `∠CBA` は、同じ二辺BA・BCで囲まれ、頂点もBなので同じ角です。一方、`∠BAC` の頂点はAで、別の角です。

三角形の一つの頂点に角が一つしかないときは `∠B` と1文字で書くこともあります。ただし、Bから複数の線が出て角がいくつもある図では、どの角か分かるよう3文字で書きます。

## よくある間違いと戻り方

最初の文字を頂点だと思い、`∠ABC` をAの角と読む間違いがあります。記号を見たら、まず中央のBへ丸を付け、BAとBCを図上で指してください。角の大きさを測る前に、対象を正しく特定することが先です。

## 自分で確かめよう

<details><summary>`∠DEF` の頂点と二つの辺は？</summary>

頂点はE、角を作る辺はEDとEFです。中央の文字が頂点です。

</details>

<details><summary>`∠XYZ` と同じ角を逆順で書くと？</summary>

`∠ZYX` です。どちらも頂点はYで、辺YXとYZに囲まれます。

</details>

Title: 頂点・辺・角を記号で書こう

Summary: 点、線分、直線、角の違いを対象の広がりから見分け、それぞれを正しい記号で表す。

# 頂点・辺・角を記号で書こう

## このレッスンの役割

このレッスンは2 / 5、読めた記号を自分で書く段階です。角では中央の文字が頂点になることを受け取り、点・線分・直線・角を区別します。完成の目安は、「AとBを結ぶ辺」「Bを頂点とする角」を混同せず記号にできることです。

## おすすめの学び方

名前だけを見る前に、対象が「場所」「二点の間」「両方へ続く線」「二本の線の開き」のどれかを言います。その後で記号を選びます。

## 今日の問い

AとBを通る線を表すとき、`AB` だけで十分でしょうか。

## 具体例で考えよう：対象の広がりで記号を選ぶ

図形の記号は、対象の種類を短く正確に伝える道具です。

| 対象 | 意味 | 書き方の例 |
|---|---|---|
| 点 | 一つの場所 | 点A |
| 線分 | 二点の間だけ | 線分AB |
| 直線 | A、Bを通り両方向へ続く | 直線AB |
| 角 | 一つの頂点から出る二辺の開き | `∠ABC` |
| 三角形 | 三つの頂点を順に結ぶ図形 | `△ABC` |

三角形ABCの「辺AB」は、AとBの間に限られた線分です。証明では「AB」と長さを表す場合もあります。直線ABは端がなく、AとBを越えて続きます。文章で「辺」「直線」と書き分けることで意味がはっきりします。

例として、Bを頂点としBAとBCで囲まれた角なら `∠ABC` と書きます。「頂点B」とだけ書くと場所しか表さず、角の開きは表せません。

## よくある間違いと戻り方

辺ABと角ABCを、どちらも `ABC` のように記号なしで書くと対象が伝わりません。点なのか、線分なのか、開きなのかへ戻り、`∠` や `△` と言葉を組み合わせてください。

## 自分で確かめよう

<details><summary>A、B、Cを頂点とする三角形はどう書く？</summary>

`△ABC` と書きます。頂点を図形の周りに順にたどって並べます。

</details>

<details><summary>Bを頂点とし、辺BAとBDに囲まれた角は？</summary>

`∠ABD` または `∠DBA` です。中央の文字をBにします。

</details>

Title: 平行・垂直の記号を読もう

Summary: 平行記号と垂直記号を二直線の関係として読み、図の矢印や直角記号と対応させる。

# 平行・垂直の記号を読もう

## このレッスンの役割

このレッスンは3 / 5、一つの対象から二直線の関係へ進む段階です。線分と直線を区別する力を受け取り、`∥` と `⊥` を言葉・記号・図で結びます。完成の目安は、記号だけを見て二直線の位置関係を説明できることです。

## おすすめの学び方

記号の形だけを覚えず、図の印と一組にします。平行では同じ矢印、垂直では交点の小さな正方形を探してください。

## 今日の問い

`l ∥ m` と `l ⊥ m` は、それぞれ二直線がどうなることを表すでしょうか。

## 具体例で考えよう：記号と図の印を対応させる

| 記号 | 読み方 | 意味 |
|---|---|---|
| `l ∥ m` | lはmに平行 | 同じ平面上で、どこまで延ばしても交わらない |
| `p ⊥ q` | pはqに垂直 | 90°で交わる |

平行記号 `∥` は等号ではありません。二つの量が同じという意味ではなく、二直線の向きの関係です。垂直記号 `⊥` は一つの角ではなく、二直線が直角で交わる関係を表します。

読み方を式のまま止めず、条件として使える文へ直すことも大切です。たとえば `l ∥ m` なら「直線lとmを別の直線が横切ると、同位角や錯角の関係を調べられる」と次の学習へつながります。`p ⊥ q` なら「交点にできる四つの角はすべて90°」と角度の情報へ変換できます。

## よくある間違いと戻り方

`l ∥ m` を「lとmの長さが等しい」と読む誤りがあります。記号の両側にあるのが数ではなく直線名であることを確認し、「何と何の関係か」を言葉に戻します。

## 自分で確かめよう

<details><summary>`a ⊥ b` の交わる角度は？</summary>

90°です。aとbは直角に交わります。

</details>

<details><summary>図で同じ矢印印が付いた二直線は何を表す？</summary>

二直線が平行であることを表します。式では `l ∥ m` のように書きます。

</details>

Title: 図の印から等しい辺・角を読み取ろう

Summary: 辺の短い線印と角の弧を対応の手がかりとして読み、等しい辺・角を記号で書く。

# 図の印から等しい辺・角を読み取ろう

## このレッスンの役割

このレッスンは4 / 5、図の印を条件へ変換する段階です。平行と垂直の印を受け取り、辺の線印・角の弧が示す等しさを読みます。完成の目安は、合同条件に使える等式を図から漏れなく書けることです。

## おすすめの学び方

同じ種類・同じ本数の印だけを一組にします。色や辺の向きではなく、印を数えてから記号に直してください。

## 今日の問い

辺ABと辺DEに同じ1本線、辺BCと辺EFに同じ2本線があるとき、どの等しさが与えられていますか。

## 具体例で考えよう：印を等式へ翻訳する

図の印は、文章で書かれた条件を短く示します。

| 図の印 | 読み取ること | 記号の例 |
|---|---|---|
| 辺に同じ1本線 | その二辺の長さが等しい | `AB = DE` |
| 辺に同じ2本線 | 別の組の二辺が等しい | `BC = EF` |
| 角に同じ1本の弧 | その二角の大きさが等しい | `∠ABC = ∠DEF` |
| 小さな正方形 | その角が90° | `∠ABC = 90°` |
| 直線に同じ矢印 | 二直線が平行 | `l ∥ m` |

1本線の辺と2本線の辺は同じ組ではありません。印の本数を変えることで、同じ図の中に複数の等しい組を表せます。

また、図が左右対称に見えても、印や仮定がなければ辺や角が等しいとは限りません。証明では「見た目」ではなく、与えられた印と既に証明した性質だけを根拠にします。

## よくある間違いと戻り方

近くにある辺や同じ色の辺を等しいと決める誤りがあります。まず同じ本数の線印を探し、その二辺の端点名を読んで等式にします。色は見やすさの補助で、数学的な根拠とは限りません。

## 自分で確かめよう

<details><summary>辺PQと辺RSに同じ3本線があるとき、何と書ける？</summary>

`PQ = RS` と書けます。線印の本数が同じなので、二辺の長さが等しいという条件です。

</details>

<details><summary>二つの角が同じ大きさに見えるが弧も条件もない。等しいと使える？</summary>

使えません。図の見た目だけでは根拠にならず、仮定や既知の性質が必要です。

</details>

Title: 角と図形の記号を診断しよう

Summary: 角・線・関係を表す記号の誤りを、頂点、対象、対応の三観点で診断し、修正する。

# 角と図形の記号を診断しよう

## このレッスンの役割

このレッスンは5 / 5、「角と図形の記号を読み直そう」の出口です。角の3文字表記、対象の種類、関係の印を受け取り、誤読の原因を一つに特定します。完成の目安は、間違った記号を直し、なぜ直したか説明できることです。

## おすすめの学び方

正解を見て写すのではなく、誤りを「頂点」「対象」「関係」「対応」のどれかへ分類します。同じ種類の間違いを次回から自分で発見できるようになります。

## 今日の問い

次の誤りは、どの約束に戻れば直せるでしょうか。

## 具体例で考えよう：最初に破った約束を探す

| 誤った読み書き | 最初の原因 | 直し方 |
|---|---|---|
| `∠ABC` の頂点をAとした | 頂点の位置 | 中央のBを頂点にする |
| 辺ABを `∠AB` とした | 対象の混同 | 辺・線分としてABと書く |
| `l ∥ m` を長さが等しいとした | 関係記号の誤読 | 二直線が平行と言い直す |
| 1本線の辺と2本線の辺を等しいとした | 対応印の誤読 | 同じ本数の印どうしを組にする |

診断の順序は、次の通りです。

1. 何を表したいかを言葉にする。
2. 点・線・角・図形・二直線の関係のどれかを決める。
3. 角なら中央の文字、合同なら頂点の対応順を確認する。
4. 図の印と記号が同じ条件を表すか確かめる。

ここでの正確さは、次の対頂角・同位角・錯角を読み取る土台です。角そのものを取り違えると、計算が正しくても別の角を求めてしまいます。

## よくある間違いと戻り方

「答えの数値が合ったから記号も合っている」と考える誤りがあります。たまたま等しい角でも、対象を正しく指定できなければ証明では使えません。数値の前に、中央の文字と二辺を確認します。

## 自分で確かめよう

<details><summary>`∠PQR` の頂点をPとした答案をどう直す？</summary>

頂点は中央のQです。辺QPとQRに囲まれた角だと説明します。

</details>

<details><summary>図の見た目だけで二辺を等しいとした答案の戻り先は？</summary>

辺の線印または問題文の仮定へ戻ります。数学的な根拠がなければ等しいとは使えません。

</details>
