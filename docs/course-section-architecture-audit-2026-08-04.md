# WakaRoute コース内セクション構成監査

- 実施日: 2026-08-04
- 対象組織: ワカルート (`a461577a-3410-4c98-b1d5-db729f3444a1`)
- 対象: 20学習パス、138コース、2,019セクション（修正後）
- 固定条件: パスとコースの分類・名称は一旦承認済みとし、コース内のセクション分けだけを評価する
- 評価対象外: レッスン数、レッスン本文、レッスンクイズ、公開状態

## 結論

138コースで十分であり、新しいコースを増やす必要はない。中学校5教科の基礎から高校入試への流れを、現在のパスとコースで収容できる。

セクション構成は全体として非常に良い。各コースに導入・前提、意味やモデル、基本技能、条件や誤解、活用、入試総合という流れがあり、コース間の学年進行も自然である。

判定は次のとおり。

|---|---:|---|
| 維持 | 138 | 現在のセクション順・境界を前提にレッスン設計へ進める |
| 軽微修正 | 0 | 2026-08-04に対象4コースを修正済み |
| 再構成 | 0 | 2026-08-04に対象3コースを再構成済み |

## 今回の評価単位

今回評価するのは「個別レッスンの品質」ではなく、「一つのコースをどの理解段階へ分けたか」である。

1. コース目標に必要な技能がセクションで網羅されているか
2. 前提から新しい意味、基本技能、方法選択、活用へ進むか
3. 各セクションに独立した出口状態があるか
4. 隣接セクションが同じ目的を重複していないか
5. 前のセクションの成果を次が利用できるか
6. 最後が単なる復習ではなく、複数技能の選択・統合・入試転移になっているか

レッスンは、承認されたセクションの内部で後から評価する。したがって、レッスンが0件であることや、現在1件しかないことを理由にセクション構成を不合格にはしない。

## 修正・再評価した7コース

以下は初回監査で見つかった問題と採用した構成である。2026-08-04にManabu MCPで反映し、全件を再取得してタイトル、順序、公開状態、重複、旧空セクションの消失を確認した。7コースはすべて「維持」へ変更した。

### 再構成1: 理科「光の反射・屈折」

現状は反射・鏡・屈折を丁寧に扱っているが、中学校の「身近な物理現象」で必要な凸レンズの働きと像が欠けている。文部科学省の現行解説でも、光の反射・屈折と並び、凸レンズの働きが明示されている。

また、現在の「反射」「用語」「角度測定」「反射の法則」は、別々のセクションというより、一つの出口状態へ向かうレッスン群としてまとめる方がよい。

推奨構成:

1. 光が見える仕組みと直進
2. 反射の法則を実験・作図で捉える
3. 乱反射と平面鏡の像
4. 屈折の規則性と見え方
5. 全反射と光の利用
6. 凸レンズの焦点と光の進み方
7. 実像・虚像と物体の位置
8. レンズの作図と身近な機器
9. 光の総合・高校入試

### 再構成2: 理科「力・圧力・浮力」

「二力がつり合う条件」「力の合成と分解の見方」は中学3年の運動とエネルギーへ移す。特に力の合成・分解は、文部科学省の現行資料でも中学校第3学年の内容として扱われている。

このコースは中学1年として、力の表し方、ばね、圧力、水圧、大気圧、浮力へ集中させる。

推奨構成:

1. 力の働きといろいろな力
2. 力の三要素・矢印・質量と重さ
3. ばねの伸びと力の規則性
4. 固体の圧力
5. 水圧と大気圧
6. 浮力と浮く・沈む条件
7. 力の実験データを分析する
8. 力・圧力・浮力の高校入試総合

### 再構成3: 理科「運動・仕事・エネルギー」

中学1年のコースから移した「二力のつり合い」「力の合成・分解」を、運動の記録より前に置く。力がどのような状態なら運動が保たれ、どのような力が速さや向きを変えるのかを理解してから、慣性・斜面・落下へ進む方が依存関係として自然である。

推奨構成:

1. 二力のつり合い
2. 力の合成と分解
3. 運動の記録と速さ
4. グラフ・平均の速さ・瞬間の速さ
5. 力と運動・慣性
6. 斜面と落下運動
7. 仕事と仕事率
8. 位置エネルギーと運動エネルギー
9. 力学的エネルギーの保存
10. 運動・仕事・エネルギーの高校入試総合

### 軽微修正1: 数学「平面図形・作図」

最終セクションが「弧の長さ・おうぎ形の面積」という新しい到達技能と、コース全体のマスターチェックを兼ねている。新規学習と総合判定を分ける。

- 現在の最終セクションを「弧の長さとおうぎ形の面積」にする
- その後に「平面図形・作図マスターチェック」を置く

### 軽微修正2: 数学「相似」

最終セクションが「立体の表面積比・体積比」という大きな新規技能と総合確認を兼ねている。新規学習後に独立した総合判定を置く。

- 現在の最終セクションを「相似な立体の表面積比・体積比」にする
- その後に「相似マスターチェック」を置く

### 軽微修正3: 国語「人物像と表現の効果」

小説・物語の人物、視点、比喩、情景は十分だが、現代詩・短歌・俳句を本文の根拠から読む出口が明示されていない。古典の音読では和歌・俳句のリズムを扱うが、現代の文学作品としての鑑賞・記述は別技能である。

「語り手と視点の効果」の後に、次を追加する。

1. 詩・短歌・俳句の話者・情景・構成
2. リズム・比喩・反復から主題を説明する

既存の比喩、反復、文末、象徴のセクションへ接続し、最終的に本文の語句を根拠に表現効果を記述させる。

### 軽微修正4: 社会「日本の自然環境・人口」

「日本列島の位置と広がり」の要約に領域は含まれるが、領土、領海、排他的経済水域、離島、周辺国、都道府県の位置が出口技能として明示されていない。高校入試では地図資料と組み合わせて問われるため、独立した境界を持たせる。

推奨する冒頭部分:

1. なぜ日本は地域差が大きい？
2. 日本列島の位置と都道府県
3. 日本の領域・領海・排他的経済水域
4. 山地の多い国土

以後は現在の地形、気候、災害、人口の順を維持する。

## 維持判定の理由

維持とした138コースは、セクションのタイトルと要約から次を確認できた。

- コース説明と最終到達点が一致している
- 前提または導入から始まり、意味・基本・条件・活用へ進む
- 隣接セクションの順序に学習上の理由がある
- 最終セクションが総合確認、資料判断、方法選択、記述、入試活用のいずれかになっている
- 教科特有の学び方を反映している
  - 数学: 意味→手順→方法選択→文章・図形への活用
  - 国語: 語句・構造→根拠→解釈→記述・比較
  - 英語: 音・語順・意味→短い運用→読解・表現
  - 理科: 現象→観察・実験→モデル・法則→考察・予測
  - 社会: 中心課題→位置・時代→背景・因果→資料根拠・判断
