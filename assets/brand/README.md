# WakaRoute app icon

- `wakaroute-app-icon.svg`: 1024 × 1024 master icon for iOS and legacy Android icons. The background is opaque and extends to every edge; do not add rounded corners before export.
- `wakaroute-app-icon-foreground.svg`: transparent foreground layer for an Android Adaptive Icon.
- `wakaroute-app-icon-background.svg`: background layer for an Android Adaptive Icon.

The essential mark is centered inside the adaptive-icon safe zone so it remains recognizable under circle, squircle, and rounded-square masks.

Brand colors:

- Deep green: `#173F3A`
- Mid green: `#24635A`
- Lime: `#D7F06D`
- White: `#FFFFFF`
