# 公式過去問リンクと内部分析データ

`official-past-exam-sources.json` は、教育委員会等が公開する公立高校入試の公式掲載ページを案内するための公開データです。問題PDF、本文、図、画像、解答、音源は収録・転載しません。

## 公開データ

- 年度、試験区分、資料の種類、公式掲載ページ、確認日を保持します。
- PDF直リンクより、年度の資料をまとめた公式掲載ページを優先します。
- 公開ページへのリンクは、その内容を複写・転載・再配布する許諾を意味しません。
- URLや資料は変更・削除される場合があるため、`verifiedAt` と公式サイトの最新情報を優先します。
- 47都道府県を収録し、オンラインで問題を確認できる場合は `materials` に `questions` を記録します。窓口配布・閲覧のみ、または問題一式のオンライン公開を確認できない場合は空配列とし、公式入試情報への入口として明示します。
- 学校詳細への関連付けは公立校のみを対象とします。ただし、学校・学科・選抜区分により共通問題を使用しない場合があるため、志望校の最新募集要項を優先します。

## 内部分析データ

独自問題を設計するための分析結果は `Data/PastExams/private/*.json` に置き、GitとWeb公開から除外します。ただし、Gitから除外されていることは著作物を自由に保存・利用できるという意味ではありません。

- 公式問題の原文、国語・英語の本文、図、写真、音源を保存しません。
- 出題技能、形式、解答に必要な手順、想定誤答だけに抽象化します。
- 独自問題は、分析した技能をもとに場面・数値関係・設問・解説を新しく作成します。
- `internal-analysis.schema.json` は内部分析JSONの構造だけを公開するもので、実データは含みません。
- 将来はリポジトリ外のアクセス制御されたストレージへ移行します。
